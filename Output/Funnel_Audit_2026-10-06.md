## Benchmarks (ordres de grandeur, pas des cibles magiques)

B2B service, trafic froid, page = pub :
- Fold clair → le visiteur sait quoi faire
- Clic CTA : on se compare à **notre** baseline dès la semaine 1, pas à un chiffre volé
- Show rate appel : souvent le 2e trou (rappel < 3 min si quelqu’un book)

## Plus gros drop-off (hypothèse, faute de data)

**#1 — le fold.** Si en 5 secondes on ne voit pas pour qui / quel résultat / quoi faire, le scroll n’existe pas.  
C’est pour ça que le copy Accueil ouvre sur la douleur (« les outils dorment ») + le résultat (« vous restez off duty ») + un bouton.

**#2 — la confiance.** Pas de cas chiffré. Donc le milieu de page vend le mécanisme et le risque inversé, pas un témoignage fantôme.

**#3 — le show.** Après le clic : un humain dans les minutes qui suivent le booking. Sinon le calendrier se remplit et se vide.
