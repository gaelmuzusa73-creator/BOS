# Principes de copywriting

Source de vérité quand BOS écrit des mots qui doivent faire agir. Distillé des chaînes et formations : Roy Furr (PAISA + conscience de marché), Sélim Niederhoffer / Les Mots Magiques, Benoit & Joseph / Les Copywriters, Sol Schub, Tyson 4D, Umar Tazkeer, Sabri Suby, Willy Baryon. À utiliser avec le skill `copy`.

Chaque principe est opinionated. Un conseiller générique pourrait dire le contraire.

---

## Cross-cutting

### Le copy, c'est de la vente. Point.
Pas de l'info, pas du branding, pas du « content writing ». Une phrase qui n'oriente pas vers une action est un brouillon. On mesure au clic, à la réponse, à l'achat — pas à « c'est bien écrit ».

### Vole les mots, n'invente pas le ton
Forums, avis, appels, commentaires. Le mot-clé Colisée = le terme d'intention le plus chargé de la niche. Tableau douleurs / peurs / désirs avant la première ligne. Si ça n'est pas sorti de leur bouche, c'est une hypothèse.

### Conscience de marché (Schwartz / Roy Furr)
Cinq étages. On ouvre à l'étage où ils sont, pas où on voudrait qu'ils soient.
1. Le plus conscient → offre, prix, garantie
2. Conscient du produit → pourquoi toi
3. Conscient de la solution → mécanisme
4. Conscient du problème → nommer la douleur
5. Inconscient → histoire et symptômes

Retargeting et liste chaude ≠ trafic froid. Salesforce débutant devait éduquer ; Salesforce aujourd'hui compare.

### PAISA pour le froid, AIDA pour le conscient, PAS pour le court
- **PAISA** (Furr) : Problem, Agitate (3 conséquences), Invalidate (3 alternatives), Solution, Ask. La story selling qui mène à l'achat, pas le voyage du héros pour le plaisir.
- **AIDA** : Attention, Intérêt, Désir, Action — minimum viable d'une pub consciente.
- **PAS** : Problème, Agitation, Solution — DM, ad, objet.

### 80 % sur le hook
Ogilvy : 80 cents du dollar pub sur le titre. Hormozi : 10× d'effort sur les 5 premières secondes. Willy : test des 5 secondes (pour qui, quel résultat, quoi faire). Si le hook est mou, le reste n'existe pas.

### Clair, visualisable, falsifiable, inimitable
Si on ferme les yeux et qu'on ne voit rien, la phrase est morte. Si tout le monde dans la catégorie peut la dire, elle est morte. « Change une industrie » = zéro. « Porté par des mannequins à Londres et des papas dans l'Ohio » = vivant.

### Features → bénéfices dans LEUR vie
« On automatise » n'est pas un bénéfice. « Ton dimanche soir n'est plus un Google Sheet » l'est. Puis une preuve (nombre, moment, citation). Jamais l'inverse.

### Une idée, une action
Deux CTA = zéro. Deux promesses = brouillard. Le P.S. existe pour la 2e chose la plus lue — pas pour recaser cinq liens.

### Le premier jet est jetable
Écrire pour penser. Capturer. Jeter. Le polish après le volume. Les copywriters qui « tapent 30 % de winners » (Sabri) n'attendent pas le chef-d'œuvre.

## Formats

### Titres qui tuent
Spécifiques, chiffrés ou sensoriels, dans le langage du lecteur. Un mot précis (Les Mots Magiques) bat dix adjectifs. Tester 5 titres, pas en épouser un par ego.

### Cold DM / email
50–90 mots. Un détail vrai sur EUX. Une question. Triple frappe : constat → angle 2 → porte de sortie. Les Copywriters : la propal vient après la conversation, pas dans le premier message.

### Email liste
Voir `email`. Objet + preview = hook. Récompenser l'ouverture. Texte brut. P.S. obligatoire.

### Site / landing
Le site est une pub pour trafic froid (Willy / Lemlist). Offre claire → structure en funnel → copy persuasif. Above the fold = les 5 secondes. Headline + sous-titre + offre + P.S. portent ~95 % d'une page longue (Sabri).

### Ads / créas
5 angles statiques valent mieux qu'une vidéo parfaite (Sabri). 80 % tried-and-true, 20 % neuf (Hormozi). Ad fatigue = normal : on refresh l'angle, pas « la marque ».

### VSL
Hook 15–30 s (pattern interrupt + pour qui + curiosité + promesse). Puis problème, mécanisme, preuve, offre, close. Le CTA de fin est écrit pour CETTE vidéo.

## Ce que BOS refuse

- Écrire sans voix du client
- Promo sur du trafic inconscient
- Preuves inventées
- Jargon et « innovant / unique / premium »
- Envoyer l'entrepreneur « suivre une formation copy »
