# Copywriting Playbook — Distillé des 7 chaînes + 5 vidéos + playlist

> Source de vérité copy pour BOS. Quand BOS doit écrire, corriger ou auditer un texte,
> il applique ces grilles dans cet ordre. Détails sources : `Video_Library.md`.
> Dernière MAJ : 2026-10-05

---

## 1. Séquence obligatoire avant d'écrire (Roy + Copywriters + Willy)

Ne jamais écrire avant d'avoir rempli ces 4 lignes :

1. **Big Idea en 1 phrase** (Roy Furr) — nouveauté + mécanisme + promesse. Si tu ne peux pas la dire simplement, tu n'es pas prêt.
2. **Marché → Message → Offre** (Les Copywriters) — qui, quel problème, quelle émotion, quel levier de décision.
3. **Offre → Structure → Copy** (Willy Baryon) — clarifier l'offre et l'architecture avant le texte.
4. **Situation actuelle / désirée / pont** (Yomi) — décrire la douleur mieux que le client, le désir, le produit comme pont.

BOS impose ce préalable à chaque copy. Pas de texte sans Big Idea.

## 2. Titres — 80% du travail (Sélim Niederhoffer + Suby + Hormozi)

- Générer **10 variantes** systématiques (intrigue + bénéfice + spécificité), scorer, tester les 2 meilleures.
- Grille hook : clarté > intelligence. Supposer que le prospect ne sait rien. Travailler les 5 premières secondes / la ligne de flottaison (Willy : pour qui, quel résultat, quelle action en 1 écran).
- **Connotation > dénotation** : auditer chaque CTA sur sa charge émotionnelle (ex Subscribe = payant/anxiogène vs Follow = léger). Un mot change le comportement.
- Recette direct response (Suby) : grosse headline + hook unique + subheadline + visuel natif style éditorial. Étudier 5 pubs/j pendant 30j pour calibrer.

## 3. Frameworks de construction

### AIDA (Suby + Umar)
Attention → Interest → Desire → Action. Chaque pub/email/landing suit AIDA. Le hook capte, la preuve désire, 1 CTA déclenche.

### Features → Bénéfices (Umar #4 + Tyson)
Ne jamais lister une feature sans "ce qui veut dire que...". Traduire chaque feature en bénéfice + preuve. Tyson : brief = screenplay (ce qu'on dit + ce qu'on voit + pourquoi on teste).

### Power words + personnalisation (Umar #2, #6)
Banque de power words FR + 1 variable de personnalisation réelle (pas {Prénom}). Personnalisation = preuve qu'on a compris leur situation, pas mail-merge.

### Email qui convertit (Hormozi 39min + Umar #7 + Sol)
Structure : objet → preview (2e objet, jamais auto-remplissage, +24% open) → hook rapide → valeur → **1 seul CTA** contextuel.
Règles : plain text, minimal images, 1-2 liens, mobile-first, éviter money-language en objet. Ratio 80% valeur / 20% vente. Cadence 3x/sem seulement si qualité tenue, sinon monter progressivement (batcher 12-24 d'avance). North star = CTR (réf Hormozi 35,7% open / 8,5% CTR). B2C lun-mar, B2B mer.

### Landing / page qui vend (Willy + Umar #11 + Sélim)
- Accueil filtre/oriente, page service crée désir, page contact déclenche action (funnel 3 pages, pas brochure).
- Audit 5 secondes : un inconnu comprend en 5s pour qui / quel résultat / quoi faire ? Viser 6%+ conversion (vs 2% marché).
- Design amplifie copy (Umar #12) : hiérarchie, preuve près du CTA, 1 action par écran.

## 4. Preuve et différenciation (Hormozi + Tyson + Copywriters)

- **Say what only you can say / Show what only you can show** : 1 preuve unique (chiffre, cas, process) par copy, pas de slogan.
- **State facts, tell truth** : chiffres vrais, sur-livrer. Confiance = conversion long terme.
- **Preuve incarnée** : trajectoire avant/après (âge, ancien métier, revenu après) > promesse abstraite. Transformer chaque témoignage en pub (Hormozi tactic 5).
- **Give secrets, sell implementation** : donner quoi/pourquoi gratuit, vendre comment/DFY. Remind > teach : rappeler fondamentaux avec nouvelles histoires.

## 5. Rituels BOS (comment on progresse)

1. **Swipe file quotidien** (Suby) : 5 pubs/j disséquées (headline/hook/offre/CTA/preuve). BOS constitue le fichier et extrait patterns.
2. **Décryptage hebdo public** (Sélim) : 1 page/email/titre analysé avec leçon réutilisable. Construit autorité + œil.
3. **Correction systématique** (Sol) : chaque texte posté reçoit grille + réécriture. BOS = mentor qui critique d'abord, propose ensuite. Bot-mentor, pas ghostwriter.
4. **Devoir hebdo noté** (Copywriters) : 1 exercice/semaine avec retour argumenté. Pas de vidéo passive.
5. **Routine Umar** : persona ChatGPT → power words → benefits → AIDA → email/landing, appliquée à chaque offre en 1 session.
6. **Protocole 45 jours** (Sol) : 1 action acquisition 40-60 min/j avec tracking, pas "finir le cours avant de prospecter".

## 6. Checklists express BOS

### Checklist Big Idea (avant tout texte)
- [ ] Nouveauté explicite ? (quoi de neuf / différent)
- [ ] Mécanisme nommé ? (pourquoi ça marche)
- [ ] Promesse spécifique + temps ? (résultat en X jours)
- [ ] Tient en 1 phrase ?

### Checklist titre (x10 variantes)
- [ ] Bénéfice clair ? Intrigue ? Spécificité (chiffre/durée) ?
- [ ] Clarté > intelligence ? Prospect froid comprend ?
- [ ] Connotation CTA vérifiée ? (peur vs légèreté)
- [ ] 5 secondes / ligne de flottaison OK ?

### Checklist email
- [ ] Objet + preview complémentaires, curiosité ?
- [ ] Hook <3 lignes ? Valeur réelle ? 1 CTA ?
- [ ] Plain text, 1-2 liens, mobile ? Pas de money-words en objet ?
- [ ] Speed-to-lead prévu ? (alerte + script <60s)

### Checklist page
- [ ] Offre claire avant structure avant texte ?
- [ ] 5 secondes : qui / résultat / action ?
- [ ] Preuve unique visible près du CTA ?
- [ ] 1 action par écran ? Funnel froid (inconnu convertit) ?
