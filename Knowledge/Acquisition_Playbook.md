# Acquisition Playbook — Distillé des 5 vidéos + 7 chaînes

> Comment BOS fait voir l'offre et convertit. Ordre d'application : CRO d'abord,
> puis UN canal maîtrisé 90 jours. Détails sources : `Video_Library.md`.
> Dernière MAJ : 2026-10-05

---

## 0. Principe mère : CRO avant trafic (StrategeMarketing + Willy + Hormozi)

- Auditer 2 taux : visiteur→prospect et prospect→client. Doubler les 2 = 4x ventes. Boucher le trou le plus faible d'abord.
- Décider au **LTV:CAC sur marge brute** (Hormozi) : CAC max = LTV/3. En dessous de 3:1, ne pas scaler. Les gros coups (30:1 à 200:1) → y verser un max quand fenêtre ouverte.
- Métrique site : viser 6%+ conversion (Willy) vs 2% marché. Sinon, trafic = remplir seau percé.

## 1. Choisir UN canal et le tenir 90 jours (Hormozi + Suby)

Les 4 seules façons de se faire connaître (Hormozi) :
1. Warm outreach, 2. Cold outreach, 3. Contenu, 4. Ads.

Règle : **un canal, un avatar, un angle** pendant 90 jours minimum. Mesurer avant de changer (anti objet-brillant).
- Si un seul choix paid → **demand generation** (créer/agiter problème devant 1000 personnes, Meta) > demand capture (Google search), plus scalable et profitable (Suby). Google + Meta = 50%+ trafic, Meta = potentiel richesse.
- Volume d'abord : More > Better > New. Quota imposé (ex 5 posts/j + 50 hooks/sem) avant débat qualité. BOS génère le volume.
- Natif ou rien : chaque créa ressemble au contenu organique du feed (format + ton news/découverte). Tester hook d'abord, 50 hooks par pub, recycler gagnantes, 20% expérimentation.

## 2. Contenu organique + SEO + GEO (Willy + Stratege + Sélim)

- **SEO 4 piliers** (Willy) : analyse concurrentielle → structure SEO-friendly → page irrésistible → domination niche.
- **GEO 2026** (Stratege + Willy) : 80% des sources citées par l'IA hors top 10 Google → optimiser pour être cité par LLM (FAQ structurée, faits, citations, réponses directes) EN PLUS de Google. BOS réécrit chaque page pour les deux.
- **Décryptage hebdo** (Sélim) : 1 analyse publique/semaine = autorité + trafic + œil copy.
- **Video IA** (Corinne 80/20) : pipeline script IA → voix → montage auto → sous-titres → publication multi-plateformes. Objectif 1 vidéo/25 min vs 4h. Humain = contrôle créatif final 20%.

## 3. Email — actif owned (Hormozi 39min)

Voir `Copywriting_Playbook.md` § Email pour la structure. Ici l'opérationnel :
- Commencer liste tout de suite, même petite. ROI 35-45x.
- **Speed-to-contact <60s** : alerte + script d'appel/DM immédiat sur chaque opt-in (+391% ventes). Staffer ce poste dès que lift prouvé.
- Batcher 12-24 emails d'avance. Qualité > fréquence. 3x/sem seulement si valeur tenue.
- Hygiène délivrabilité + CTR north star + timing B2C lun-mar / B2B mer.

## 4. Cold email B2B — système <100$ (Lead Gen Jay 7h)

Ne scaler que si les 3 piliers sont verts, sinon spam = argent brûlé :

1. **Infra** : domaines secondaires (jamais principal) + SPF/DKIM/DMARC + warmup + inbox placement tests (Instantly.ai ou équivalent).
2. **Liste** : ICP précis → B2B DB vs scraping vs signals → hack Apollo -80% → vérification catchall + qualif IA + nettoyage.
3. **Offre + copy** : rendre offre irrésistible d'abord (bait, lead magnet inversé), puis copy triple tap + spintax anti-spam + personnalisation réelle.

Puis : CRM + gestion réponses + UTM + SOPs + équipe. Scale jusqu'à 10K/j seulement quand reply rate tient. Ajouter omnicanal (ads + voicemail + social) + perso IA en phase avancée. BOS construit SOPs et tracking.

## 5. Funnel site 3 pages (Willy)

Pas de brochure. Funnel froid :
- Accueil filtre/oriente → Service crée désir → Contact déclenche action.
- Règle 5 secondes + Offre/Structure/Copy dans cet ordre.
- Preuve : +12 leads semaine 1 après refonte 3 pages (cas agence).

## 6. Testing permanent DTC (Tyson 4D)

- Une ad qui cartonne meurt en ~6 semaines (fatigue créative). Marques qui scalent (600k→1M$ spend) = flux d'angles permanent.
- Pipeline hebdo : lun recherche (Amazon/Reddit) → mar 5-6 concepts → mer briefs screenplay → jeu/ven lecture ROAS/CPA → itération.
- Brief exigé pour chaque ad : visuel + hook + angle émotionnel + raison du test.
- Pour décrocher clients sans expérience : kit Loom (3 spec ads + script stratégie + 20 prospects DTC). BOS produit le kit en 1 session.

## 7. Automatisation 80/20 (Corinne)

- Chaque workflow : output IA → checklist humaine 20% (contrôle créatif).
- Chiffrer temps avant/après IA pour chaque tâche (ex vidéo 4h → 25 min).
- Automation prédictive : si tâche en retard 24h+ → alerte + plan proposé, pas juste rappel. Appliquer à prospection, contenu, projet.
- Application agence : monter capacité sans recruter, cibler francophones (France/Afrique/Canada).

## 8. Plan 90 jours type (BOS impose)

- Semaines 1-2 : CRO audit + fix maillon faible + LTV:CAC + Big Idea + page 5 secondes + GEO.
- Semaines 3-12 : UN canal à fond avec quota volume + swipe file quotidien + décryptage hebdo + email 1→3x/sem + speed-to-lead.
- Si B2B : infra + liste 500 vérifiés + offre/bait + triple tap, puis scale mesuré.
- Si DTC/paid : pipeline 5-6 concepts/sem + briefs + lecture data.
- Tout est tracké : 5 métriques max (revenue, clients, CAC, conversion, marge) chaque semaine.
