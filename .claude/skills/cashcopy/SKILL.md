# Skill: Cashcopy

Démonter une pièce qui a déjà fait de l'argent, et reconstruire la mécanique sur ton offre. Déclenché quand une pub, une page ou un email gagnant existe (le tien ou celui d'un marché proche) et qu'on veut le même effet sans copier le texte. Sources : Sol, Les Copywriters.

## Objectif

Fin de session : **la fiche de démontage** (angle, preuve, offre, CTA) et **ta version**, phrase par phrase originale. Fichier `Output/Cashcopy_[date].md`.

**Critères de succès :** aucune phrase reprise. Le mécanisme est nommé. La preuve est la tienne ou absente, jamais inventée.

## Croyances

- **On vend une décision défendable.** Le lecteur doit pouvoir se dire pourquoi c'est raisonnable. Une liste de features ne défend rien.
- **Les mots du prospect battent le style.** Si la recherche n'est pas faite, le démontage reste du plagiat déguisé.
- **Une pièce qui a imprimé du cash se démonte en quatre.** Angle, preuve, offre, CTA. On reproduit ces quatre, pas les adjectifs.
- **En B2B, la pertinence et la preuve battent l'urgence factice.** Un compte à rebours fait fuir un acheteur professionnel.
- **L'IA accélère le brouillon après la fiche.** Elle ne choisit pas l'angle et elle n'invente pas le cas client.
- **Devenir copywriter freelance est un autre business.** On ne le propose pas à côté du business en cours. Ce skill sert l'offre actuelle.

## Process

### Phase 0 — Pré-check

Il faut une pièce source : URL, capture, ou texte. **Si rien →** ne pas inventer un « winner ». Partir sur `bigidea` puis `copy`.

**Si l'offre à écrire n'existe pas →** `offer`.

### Phase 1 — Démontage

BOS remplit, à partir de la pièce source :

- **Angle.** Quelle tension ouvre.
- **Preuve.** Quel fait rend ça croyable.
- **Offre.** Quel deal, quel risque.
- **CTA.** Quelle action unique.
- **Ce qu'on ne prend pas.** Les phrases, le nom, les chiffres d'autrui.

### Phase 2 — Reconstruction

Réécrire les quatre blocs pour ton client, tes preuves, ton prix. Appeler `bigidea` si le type d'idée n'est pas évident.

Le brouillon IA vient après cette fiche, pas avant.

### Phase 3 — Livrer la pièce

La version finale est une page, une pub ou un email complet. L'enchaînement se fait dans `page`, `creative` ou `email` si le format l'exige. Sinon la pièce est dans le fichier de ce skill.

## Output

```markdown
# Démontage — [date]

- **Source :** [lien ou description, pas le texte collé]
- **Angle :**
- **Preuve :**
- **Offre :**
- **CTA :**

## Ta version
[texte original]
```

| Fichier | Contenu |
|---------|---------|
| `Output/Cashcopy_[date].md` | Fiche + texte |
| `Core/Actions.md` | Publication ou envoi |

## Garde-fous

- **Ne JAMAIS coller le texte source, même « pour s'inspirer dans le fichier ».** → Quatre blocs, puis réécriture.
- **Ne JAMAIS transférer le chiffre d'un autre sur ton offre.** → Tes preuves, ou aucune.
- **Ne JAMAIS proposer une reconversion copywriter.** → Le texte sert ton business.
- **REFUSE l'urgence factice en B2B.** → Pertinence, preuve, prochaine étape petite.
