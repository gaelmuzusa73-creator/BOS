# Skill: Creative

Produire un angle de pub qui peut vendre, puis le brief, puis le texte. Déclenché quand le canal est la pub ou le contenu court qui doit vendre. Source : Tyson 4D.

## Objectif

Fin de session : **un brief** (recherche, angle, accroche, script ou texte d'image) et **une pièce** prête à tester. Fichier `Output/Creative_[date].md`.

**Critères de succès :** l'angle surprend quelqu'un qui a déjà vu les pubs du marché. Le texte peut être moche. Il est spécifique. L'IA n'a pas écrit avant le brief.

## Croyances

- **Le job n'est pas le plus beau texte.** C'est celui qui bouge les chiffres. Une pub moche qui vend bat une pub léchée qui ne vend pas.
- **L'angle vient de l'écart.** Ce que le client sait déjà, contre ce qui le surprendrait encore. Répéter l'angle que le marché a lu cent fois, c'est payer pour être ignoré.
- **L'ordre est fixe.** Recherche → idée → brief → texte. Pas de page blanche. Pas de prompt jeté dans le vide.
- **Le hook est la pub.** Les cinq premières secondes, ou la première ligne de l'image, cadrent tout le reste. 80 % de l'effort va là.
- **Clair bat malin.** Si l'accroche a besoin d'une explication, on garde l'explication et on jette l'accroche.

## Process

### Phase 0 — Pré-check

**Offre floue →** `offer`.

**Idée de campagne absente →** `bigidea`, puis revenir avec la phrase.

**Pas de budget pub et pas d'endroit où poster →** écrire quand même la pièce si elle peut partir en organique. Sinon ne pas faire semblant de « lancer des ads ».

### Phase 1 — Recherche courte

Minimum avant le brief :

- 5 douleurs dans les mots du client.
- 3 angles déjà utilisés par les concurrents (à ne pas répéter).
- 1 fait, chiffre ou symptôme que le marché n'a pas encore mis en accroche.
- Les preuves qu'on a le droit d'utiliser.

BOS fait la recherche publique. L'entrepreneur donne les objections entendues et les cas réels.

### Phase 2 — Brief

Une page :

- Audience en une phrase.
- Angle en une phrase (l'écart).
- Accroche (5 secondes ou première ligne).
- Preuve.
- CTA.
- Ce que la pub ne doit pas dire.

### Phase 3 — Pièce

Format selon le canal :

- **Image statique.** Accroche, une ligne de preuve, CTA. Pas de pavé.
- **Script court.** Hook → une idée → preuve → CTA. Ça peut ressembler à une info (fait, tension), pas à une affiche.

Variante : une seconde accroche sur le même angle, pour un test. Pas un second angle dans la même session.

### Phase 4 — Livrer

`Output/Creative_[date].md`. Action : mettre en ligne ou tourner la vidéo avec ce script.

Dire : « Si tu veux la rendre plus jolie avant de la publier, dis-le. On publie d'abord, on embellit le gagnant. »

## Garde-fous

- **Ne JAMAIS ouvrir par un prompt IA.** → Brief d'abord.
- **Ne JAMAIS proposer cinq angles « pour voir ».** → Un angle, deux accroches.
- **Ne JAMAIS retenir une créa parce qu'elle est belle.** → Spécifique et publiable.
- **REFUSE de copier le script d'une pub concurrente.** → Le démontage se fait dans `cashcopy`, la réécriture ici.
